# Mars Vanguard

Mars Vanguard is a Unity 3D game project.

## Requirements

- Unity Hub
- The Unity Editor version recorded in `ProjectSettings/ProjectVersion.txt`

## Getting Started

1. Clone this repository.
2. Open the project through Unity Hub.
3. Allow Unity to regenerate its local `Library` and editor files.
4. Open a scene from `Assets/Scenes` and press Play.

## Project Structure

- `Assets/` - scenes, scripts, models, materials, prefabs, UI, audio, and other game content
- `Packages/` - Unity package manifest and lock file
- `ProjectSettings/` - Unity project and editor settings

Generated folders and local build artifacts are excluded through `.gitignore`.
